# Network diagrams

These diagrams depict example and local configurations, not proof of the
current deployment. The team selects and validates actual values under delegated
range authority; see the [provisioning guide](../../citef-config/README.md).
The Windows forwarder has a documented
[TLS configuration limitation](../deployment/splunk-sysmon-ingest.md#receiver-prerequisites)
that a connection shown here does not resolve.
